# Design System

* **Primary Theme:** Premium Modern Dark Theme (Glassmorphism)
* **Background Color:** #030712 (Gray 950) with subtle radial gradients.
* **Primary Accent Color:** #3B82F6 (Blue 500)
* **Secondary Accent Color:** #8B5CF6 (Violet 500)
* **Tertiary/Highlight Color:** #10B981 (Emerald 500)
* **Typography:** System-ui, UI-sans-serif, Inter (Monospace for tech accents).
* **Component Styling:** Use glass panels (`bg-[rgba(17,24,39,0.7)]` with `backdrop-blur-md`), rounded corners (`rounded-2xl` or `rounded-3xl` for modals), subtle white borders (`border-white/5`), and high whitespace spacing.
* **Animations:** Framer motion for layout transitions, SVG dash-array tricks for technical visualizers, and CSS 3D transforms for depth.
* **Responsiveness:** All components must be mobile-first using Tailwind flex/grid.
